# Planfo CMS — Version 1.0.0 (v1 Release)

## Release Overview
**Version:** `v1.0.0` (Production Release v1)  
**Date:** November 9, 2026  
**Status:** General Availability (GA) — Promoted from Beta  

Planfo CMS Version 1.0.0 represents the complete transition from the initial beta prototype to the official production release. All core features iterated and finalized during beta have been unified into the production Violet Design System, single-port architecture, and three-panel studio workspace.

---

## Key Updates & Enhancements in v1.0.0

### 1. Unified Single-Port Architecture (WordPress-Style)
* **Single Origin Port (`:3001`):** Eliminated dual-port complexity (Vite dev server on `:5173` and Express backend on `:3001`).
* **Route Mapping:**
  * Public Website: `http://localhost:3001/`
  * Admin Dashboard: `http://localhost:3001/admin/`
  * Static Assets & API: Unified under single origin with zero CORS overhead and persistent authentication cookies.

### 2. Dual-State Expandable & Collapsible Sidebar Rail
* **Collapsed Mode (`w-16` / 64px):**
  * Displays the vector Planfo icon mark (`<PlanfoLogo variant="icon" />`).
  * High-visibility action buttons with clean hover tooltips (`fixed left-20 ...`).
  * Live status dots on collections with unread/pending items (Trash, Dynamic Blueprints).
  * Expand toggle control (`keyboard_double_arrow_right`).
* **Expanded Mode (`w-64` / 256px):**
  * Full vector brand wordmark (`<PlanfoLogo variant="full" />`).
  * Dynamic site/project title loaded from `/api/settings` with `• Static` indicator.
  * Fully categorized sections:
    * `CONTENT`: Pages, Posts, Products
    * `BLUEPRINTS & TAXONOMY`: Blueprints Studio, Categories & Tags, Feature Packs Hub
    * `COLLECTIONS`: Dynamically instantiated custom blueprint collections with entry count badges
    * `ASSETS & NAV`: Media Library, Navigation Menus, Themes
    * `SYSTEM & CONFIG`: Users & Roles, Site Settings & SEO, Revisions, Backups, Trash
  * Quick "Visit Live Site" launcher link showing current port (`:3001`).
  * Profile dropdown with user metadata, avatar, and logout.
  * Collapse toggle control (`keyboard_double_arrow_left`).
* **Sidebar State Persistence:** Saved in `localStorage` under `planfo_sidebar_collapsed`.

### 3. Attached Block Composer Palette (No Floating Overlays)
* **Docked Left Studio Panel:**
  * Replaced detached `fixed left-20 top-32` floating elements with a dedicated column docked flush against the sidebar navigation across:
    * `apps/admin/src/pages/Posts/PostEdit.tsx` (Articles Studio)
    * `apps/admin/src/pages/Pages/PageEdit.tsx` (Page Builder)
    * `apps/admin/src/pages/Blueprints/DynamicEntryEdit.tsx` (Custom Collections)
    * `apps/admin/src/pages/Products/ProductEdit.tsx` (Product & Catalog Studio)
* **Expanded State (`w-64`):**
  * Two-column block inserter grid (Headings, Paragraphs, Media, Quotes, Lists, Tables, Code).
  * Search, block count indicators, and keyboard shortcuts (`⌘K`).
  * Collapse button (`keyboard_double_arrow_left`).
* **Minimized State (`w-16` / 64px):**
  * High-visibility vertical icon rail identical in aesthetic to the main sidebar rail.
  * Primary widget button and expand button (`keyboard_double_arrow_right`).
  * Direct one-click quick inserters for Headings, Paragraphs, and Media with floating tooltips.

### 4. Header Standardization
* **Removed Redundant Brand Logos:** Top headers across all inner editor pages start directly with breadcrumbs and live tokens (`v2.4 Live Tokens`).
* **Clean Action Toolbar:** Standardized right-side controls to Preview (`visibility`), Save/Publish, and Profile dropdown.

### 5. High-Contrast & Design System Integrity
* **Contrast Compliance:** Addressed all white-on-light font colors across Navigation Menus, Themes, Settings, Trash, and Structured Editor.
* **Middle Canvas Isolation:** 24px (`px-6`) side padding on the middle canvas with independent scrolling; left sidebar rail and right inspector panels remain fixed.
